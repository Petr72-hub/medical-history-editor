# История болезни

Локальный учебный редактор историй болезни для взрослых и детей. Работает в браузере без сервера, регистрации и установки зависимостей.

## Запуск

Скачайте репозиторий и откройте `index.html` в Chrome или Edge. Все файлы приложения должны оставаться в одной папке. Шрифты поставляются локально вместе с лицензией IBM Plex Sans.

## Текущая версия

- Отдельные взрослый и детский шаблоны, 17 разделов, начиная с паспортной части.
- Варианты описания признаков, пункт «Другое», подробности и свободные дополнения.
- Несколько историй с переключением через список и автоматическим сохранением.
- Предпросмотр, экспорт DOCX, печать и PDF через диалог печати браузера.
- Пустые поля и разделы не включаются в документ.
- Температурная таблица без пустых строк и полностью пустых столбцов.
- Отдельная краткая самопроверка осмотра ребёнка; её отметки не попадают в историю.
- Резервное копирование и импорт JSON без замены существующих историй.
- Подписи источников под полями удалены.

## Хранение

Истории находятся в localStorage конкретного браузера и не входят в репозиторий. Перед переносом приложения, сменой профиля или очисткой браузера скачайте резервную копию JSON. Импортируйте её после переноса. Пароля и шифрования в этой версии нет.

## Пока не реализовано

- Отдельный экран обзора всех историй с поиском.
- Вход через Google и синхронизация с Google Drive. OAuth Client ID ещё не настроен; облачное сохранение отсутствует.
- Графические кривые температурного листа.

Приложение не формирует диагнозы, назначения или медицинские заключения автоматически.

## Учебные источники

Структура основана на предоставленной методичке Тюменского ГМУ «Оформление истории болезни» (2023). Детские разделы дополнены по пособию «Чек-листы самопроверки при физикальном обследовании ребёнка». Отдельные варианты общего осмотра сверены по выбранным страницам Куликова, Ивашкина и Гребенева; полная оцифровка учебников не проводилась.

PDF и учебники оставлены локально и не загружаются в GitHub. Редактор работает без них; для работы ссылок на пособия добавьте собственные файлы по инструкции в `sources/README.md`.

## Проверки перед сохранением версии

Проверены сценарии выбора и уточнений, сохранение после перезагрузки, старые черновики, JSON-импорт, исключение пустых полей из DOCX и отображение на ширинах 1440, 768 и 390 пикселей. Тестовые истории в репозиторий не включены.
